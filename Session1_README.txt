Session 1 - API Backend Application
Platform: Kotlin, Spring Boot 3.4.3
Database: PostgreSQL (port 5432, database: worldskills, user: omeg, password: Omega)
Server Port: 5127

How to launch the application:
1. Ensure PostgreSQL is running on port 5432 with database 'worldskills'.
2. Open terminal in the project directory.
3. Run: ./gradlew bootRun
4. The server will start on http://localhost:5127
5. All database tables and initial sample data will be initialized automatically upon launch.
