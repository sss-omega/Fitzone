1. ИДЕНТИФИКАЦИЯ И АУТЕНТИФИКАЦИЯ
--------------------------------------------------------------------------------

1.1 POST /api/register
Описание: Регистрация нового клиента в сети FitZone.
Заголовки: Content-Type: application/json
Обязательные параметры:
  - first_name (string): Имя клиента
  - last_name (string): Фамилия клиента
  - email (string): Корректный адрес электронной почты
  - password (string): Пароль (хэшируется алгоритмом SHA-256)
  - security_question (string): Секретный вопрос для восстановления доступа
  - security_answer (string): Ответ на секретный вопрос (хэшируется SHA-256)
Необязательные параметры:
  - phone (string): Номер телефона (например, +7 701 123 45 67)
  - is_subscribed_to_newsletter (boolean): Флаг согласия на получение рассылки

Пример запроса:
POST /api/register
{
  "first_name": "Айгерим",
  "last_name": "Нурланова",
  "email": "aigerim.new@example.com",
  "password": "FitLife2024",
  "phone": "+7 701 234 56 78",
  "security_question": "Кличка первого питомца?",
  "security_answer": "актос",
  "is_subscribed_to_newsletter": true
}

Пример успешного ответа (HTTP 201 Created):
{
  "success": true,
  "message": "Регистрация прошла успешно",
  "token": "4e1a65f0-61b9-4f77-938b-70c8f5d04581",
  "user": {
    "id": 5,
    "email": "aigerim.new@example.com",
    "first_name": "Айгерим",
    "last_name": "Нурланова",
    "phone": "+7 701 234 56 78",
    "is_subscribed_to_newsletter": true,
    "subscription_type": "Standard"
  }
}

Пример ошибки (HTTP 400 Bad Request / 409 Conflict):
{
  "error": "Пользователь с таким email уже зарегистрирован"
}


1.2 POST /api/login
Описание: Аутентификация клиента по электронной почте и паролю.
Заголовки: Content-Type: application/json
Обязательные параметры:
  - email (string): Email пользователя
  - password (string): Пароль пользователя

Пример запроса:
POST /api/login
{
  "email": "testclient@fitzone.kz",
  "password": "FitZonePass.2026"
}

Пример успешного ответа (HTTP 200 OK):
{
  "success": true,
  "token": "a1b2c3d4-e5f6-7a8b-9c0d-1e2f3a4b5c6d",
  "user": {
    "id": 3,
    "email": "testclient@fitzone.kz",
    "first_name": "Тест",
    "last_name": "Клиент",
    "phone": "+7 777 111 22 33",
    "profile_image": "/images/default_avatar.png",
    "is_subscribed_to_newsletter": true,
    "subscription_type": "Gold"
  }
}

Пример ошибки (HTTP 401 Unauthorized):
{
  "error": "Неверный логин или пароль"
}


1.3 POST /api/forgot-password
Описание: Инициирование процесса сброса пароля (получение секретного вопроса).
Заголовки: Content-Type: application/json
Обязательные параметры:
  - email (string): Email пользователя

Пример запроса:
POST /api/forgot-password
{
  "email": "testclient2@fitzone.kz"
}

Пример успешного ответа (HTTP 200 OK):
{
  "email": "testclient2@fitzone.kz",
  "security_question": "Название вашего первого учебного заведения?"
}

Пример ошибки (HTTP 404 Not Found):
{
  "error": "Пользователь с таким email не найден"
}


1.4 POST /api/reset-password
Описание: Проверка ответа на секретный вопрос и установка нового пароля.
Заголовки: Content-Type: application/json
Обязательные параметры:
  - email (string): Email пользователя
  - security_answer (string): Ответ на секретный вопрос
Необязательные параметры:
  - new_password (string): Новый пароль (если передается вместе с ответом)

Пример запроса (проверка ответа):
POST /api/reset-password
{
  "email": "testclient2@fitzone.kz",
  "security_answer": "Абай"
}

Пример ответа подтверждения (HTTP 200 OK):
{
  "success": true,
  "verified": true,
  "message": "Секретный ответ подтвержден. Введите новый пароль."
}

Пример запроса с новым паролем:
POST /api/reset-password
{
  "email": "testclient2@fitzone.kz",
  "security_answer": "Абай",
  "new_password": "NewSecretPass2026"
}

Пример успешного ответа (HTTP 200 OK):
{
  "success": true,
  "message": "Пароль успешно обновлен. Теперь вы можете войти с новым паролем."
}

Пример ошибки (HTTP 400 Bad Request):
{
  "error": "Неверный ответ на секретный вопрос"
}

2. УПРАВЛЕНИЕ ПРОФИЛЕМ КЛИЕНТА
--------------------------------------------------------------------------------

2.1 GET /api/profile
Описание: Получение данных личного профиля клиента.
Заголовки: Authorization: Bearer <TOKEN>

Пример успешного ответа (HTTP 200 OK):
{
  "id": 1,
  "email": "aigerim.n@example.com",
  "first_name": "Айгерим",
  "last_name": "Нурланова",
  "phone": "+7 701 234 56 78",
  "profile_image": "/images/aigerim_n.jpg",
  "is_subscribed_to_newsletter": true,
  "subscription_type": "Premium",
  "preferred_workout_type": "Групповые занятия"
}


2.2 PUT /api/profile
Описание: Обновление информации в профиле клиента (включая фото и пароль).
Заголовки: 
  - Authorization: Bearer <TOKEN>
  - Content-Type: application/json
Параметры (любые обновляемые):
  - first_name (string): Имя
  - last_name (string): Фамилия
  - phone (string): Номер телефона
  - profile_image (string): Ссылка на изображение
  - is_subscribed_to_newsletter (boolean): Статус подписки на рассылку
  - password (string, optional): Новый пароль

Пример запроса:
PUT /api/profile
{
  "first_name": "Айгерим",
  "last_name": "Нурланова",
  "phone": "+7 701 999 88 77",
  "profile_image": "/images/aigerim_n.jpg",
  "is_subscribed_to_newsletter": true
}

Пример успешного ответа (HTTP 200 OK):
{
  "success": true,
  "message": "Профиль успешно обновлен",
  "profile": {
    "first_name": "Айгерим",
    "last_name": "Нурланова",
    "phone": "+7 701 999 88 77",
    "profile_image": "/images/aigerim_n.jpg",
    "is_subscribed_to_newsletter": true
  }
}

3. УПРАВЛЕНИЕ ИЗБРАННЫМИ ЗАЛАМИ (FAVORITE CLUBS)
--------------------------------------------------------------------------------

3.1 GET /api/favorite-clubs
Описание: Получение списка избранных залов клиента с отметкой основного зала.
Заголовки: Authorization: Bearer <TOKEN>

Пример успешного ответа (HTTP 200 OK):
[
  {
    "id": 1,
    "club_id": 1,
    "name": "FitZone Достык, Алматы",
    "address": "пр. Достык, 120",
    "city": "Алматы",
    "is_main": true
  },
  {
    "id": 2,
    "club_id": 2,
    "name": "FitZone Аль-Фараби, Алматы",
    "address": "пр. Аль-Фараби, 77/8",
    "city": "Алматы",
    "is_main": false
  }
]


3.2 POST /api/favorite-clubs
Описание: Добавление фитнес-зала в список избранных.
Заголовки: 
  - Authorization: Bearer <TOKEN>
  - Content-Type: application/json
Обязательные параметры:
  - club_id (integer): ID зала из базы данных
Необязательные параметры:
  - is_main (boolean): Сделать основным залом (default: false)

Пример запроса:
POST /api/favorite-clubs
{
  "club_id": 3,
  "is_main": false
}

Пример успешного ответа (HTTP 201 Created):
{
  "success": true,
  "message": "Зал успешно добавлен в избранное",
  "club_id": 3,
  "is_main": false
}


3.3 PUT /api/favorite-clubs/{id}
Описание: Отметить указанный зал как основной.
Заголовки: Authorization: Bearer <TOKEN>

Пример запроса:
PUT /api/favorite-clubs/2

Пример успешного ответа (HTTP 200 OK):
{
  "success": true,
  "message": "Зал успешно отмечен как основной"
}


3.4 DELETE /api/favorite-clubs/{id}
Описание: Удаление зала из списка избранных залов клиента.
Заголовки: Authorization: Bearer <TOKEN>

Пример запроса:
DELETE /api/favorite-clubs/2

Пример успешного ответа (HTTP 200 OK):
{
  "success": true,
  "message": "Зал удален из избранного"
}
